音效对照与预览

集中预览本次确认的 2 个交互操作音，以及既有 15 个状态 / 告警 / 错误音。

交互操作音

本轮选定 B. Warm Tap。有效触摸 / 有效按键只在实际 UI 或业务动作发生时发声；USB-C 插入只在 attach 上升沿发声。

ID用途路由预览
interaction_touch有效触摸 / 有效按键ACTION
usb_c_insertUSB-C 插入ACTION

状态 / 告警 / 错误音

既有 speaker_chime_v1 运行时提示音保持原语义：状态音单次播放，告警音按 2000ms 间隔循环，错误音连续循环。

ID分类触发语义预览
boot_startupstatus系统上电启动成功后触发
mains_present_dcstatus检测到 DC 桶输入恢复时触发
charge_startedstatus充电状态从未充电切换为充电中时触发
charge_completedstatus充电状态进入完成态时触发
shutdown_mode_enteredstatus系统进入关闭模式流程时触发；当前主固件保持 dormant
mains_absent_dcwarningDC 桶输入丢失时触发间隔循环
high_stresswarning任一模块温度 / 负载不佳但未触发保护时触发间隔循环
battery_low_no_mainswarning电池低电且市电不存在时触发间隔循环
battery_low_with_mainswarning电池低电且检测到市电时触发间隔循环
shutdown_protectionerror任一模块触发保护动作导致停机时连续循环
io_over_voltageerror输入或输出检测到过压时连续循环
io_over_currenterror输入或输出检测到过流时连续循环
io_over_powererror输入或输出检测到过功率时连续循环；当前主固件保持 dormant
module_faulterror部分硬件通信失败期间连续循环
battery_protectionerrorBMS 触发保护时连续循环
