# 电芯与电池组资料

Mains Aegis 选用 EVE 亿纬 INR21700/50E，组成 4S1P 电池组。本文集中保存电芯公开依据、电池组推导、项目使用边界及资料要求；具体软件和 Data Flash 预期值统一见[电池系统配置对账清单](battery-configuration.md)。

## 2. 电池组构成与推导

| 项目 | 项目选型或计算 | 限制 |
| --- | --- | --- |
| 串并联 | 4S1P，4 节电芯串联 | 串联增加电压，不把容量相加为 20Ah |
| 标称容量 | 5.0Ah | 受最弱单节、一致性、温度及终点限制 |
| 标称电压 | 4×3.65=14.6V | 不是恒定输出电压 |
| 标称能量 | 14.6×5.0≈73Wh | 铭牌推算；未包含转换损耗和保守截止造成的不可用能量 |
| 电芯满充电压对应整包值 | 4×4.2=16.8V | 实际充电还受 BMS 请求、温度与充电器限制 |
| 项目正常容量仿真终点 | 4×2.8=11.2V | 项目设计值；独立于单节欠压保护 |
| 厂家 2.5V 终点的整包算术值 | 10.0V | 不是允许忽略最低单节、持续放到整包 10V 的操作指令 |
| 连接方式 | 四个 21700 电池座 | 可拆卸不代表带电热插拔；接触阻抗与温升需实测 |
| 布局 | 电池座、充电器、BMS 共板，约 10cm×10cm、四层 PCB | 热耦合与低流计量需要板级证据 |

### 三个不同的“截止”

- **容量模型终点：** BQ40 IT Term Voltage，项目选择 11200mV，用于估计正常可用容量。
- **单节欠压保护：** 项目 CUV Threshold 设计为 2500mV/节，恢复 2550mV/节；与 Term Voltage 分开管理，须结合保护延时、使能和恢复条件核对。
- **系统停止供电：** 还受固件策略、转换器输入能力、负载瞬态、温度及最低单节状态限制；整机可用能量与截止行为须按实际负载独立验证。

采用 2.8V 正常终点的目的，是在公开 2.5V 测试终点之前结束正常容量预算。实际可用容量需要测量；不强制深放电来凑齐额定容量。电芯不均衡时，整包电压正常也可能已有单节欠压。

## 3. 充电与温度使用边界

| 项目 | 项目策略 | 证据状态 |
| --- | --- | --- |
| 电芯充电温度 | 0°C≤T<45°C | 项目执行窗口，最终需采购批次规格确认；不声称厂家允许任意低温快充 |
| 0～15°C 充电 | 100mA，约 0.02C | 固件与温度 profile 联锁 |
| 15～45°C 普通充电 | 500mA，约 0.1C | 仍受新鲜 BMS 请求和所有保护限制 |
| 正常满充协调 | BQ40 taper 120mA，BQ25792 ITERM 80mA | 项目目标，须验证完整自然终止过程 |
| 电芯温度采样 | TS2～TS4 取最高有效值，TS1 为板侧点 | 三个点不等于四节各有独立表面温度证据 |
| 温度器件 | 10kΩ@25°C、β3380 NTC；充电器独立 NTC | NTC 贴合、温差和故障检测仍需板级验证 |
| 储存与闲置 | 依采购批次正式条款制定 SOC、温度与时限 | 尚未完成批次级规范；不编造储存寿命或免维护承诺 |

BQ40 满充资格成立后，充电器可能继续完成尾段，这是联合终止策略的一部分；出现安全保护时则立即停止。OC 容量过充保护与自然满充终止必须分别记录；SOC99、容量达到某个值或 CHG FET 关闭均不能独立证明满充完成。

## 4. 测量、均衡与保护硬件

| 项目 | 设计信息 | 解释与待验证项 |
| --- | --- | --- |
| 主 BMS | BQ40Z50RSMR-R2 | 电量计、保护、FET 控制和均衡；不同状态来源须分别读回 |
| 检流电阻 | R28，1mΩ，1206，≥1W，±1% 或更优，TCR≤50ppm/°C | Kelvin 取样；具体料号和板级误差仍须留档 |
| 电流符号 | BQ40 fresh Current() 正值充电、负值放电 | 缓存、AverageCurrent 与 fresh 采样时刻不同，不能直接当同一瞬时值 |
| 外部被动均衡 | SI2305A PMOS＋16Ω、≥2W 电阻；平均目标 200mA | 目标不是实测；需考虑电压、占空比、开关和电阻温升 |
| 均衡信息 | mask、各自采样时间、单节电压与温度 | mask 只能证明观察到开关状态；不能证明整包有同值充电电流 |
| 二次过压链 | BQ296100DSGR，4.35V/节；AO3400A 驱动 CLM1612P1412 heater | 独立于正常容量模型；熔断属于故障保护，不是常规停充方式 |
| 熔断器件规格 | 4S／12A | 不能直接推导整机允许长期输出 12A |
| 连接安全 | 电池座、单节采样线、CHG／DSG 高边开关 | 带电断接可能引起异常采样或 PF／熔断；更换应遵守安全断电流程 |

对 1mΩ 检流电阻，480mA 对应约 0.48mV。电流核对必须同步记录检流电阻电压、仪表条件、fresh Current、AverageCurrent、缓存时间和均衡 mask。均衡期间的读数差异不能仅凭开关状态归因为电气干扰；PCB 接地与 Kelvin 路径的效果须通过同步测量验证。

电芯官方 15A 放电参数不等于本机已验证的持续电池电流。电池座、走线、FET、检流、熔断器、散热与转换器共同限制输出；19V／约 120W 等设计目标必须单独通过电气和热验收，不从电芯额定值直接背书。

## 5. 容量模型与学习数据

DesignCapacity 表示项目设计额定容量；FCC 表示电量计依据温度、负载、阻抗和终点等条件计算的可用满充容量；Qmax 是学习得到的化学容量参数。三者不能互相替代，也不能仅由 FCC 与铭牌容量的差异推断电芯健康状态。

ChemID 必须来自与电芯相匹配的 TI 化学模型及匹配证据，不能从型号直接臆填，也不能仅改写 ChemicalID 数值代替模型导入。模型资格验证需结合正常充放电、静置、有效终止和校准记录。

设计容量和仿真终点更正不默认清理 Qmax、Ra、校准或历史；按设备保存配置应用前后的数据。重新学习必须有独立依据与流程，不通过清零历史或放宽保护绕过模型问题。实机数值、异常分析和应用结果保存于独立调查或验证报告。

## 6. 采购与验证资料归档要求

1. 四节实物的批次、日期码、位置编号、供应商与正式规格书；确认尺寸、重量、最小容量与温度条款。
2. 采购批次的认证／运输资料、厂家储存及寿命测试条件，不用官网宣传值替代。
3. ChemID 匹配报告、校准记录与逐节一致性证据；量化电池座接触电阻及热表现。
4. 按配置对账清单保存应用前后记录、完整保护配置读回及学习历史。
5. 同一候选的充电稳定采样、自然终止、终止后观察及正常负载可用能量验证；分别记录未覆盖的均衡 mask。
