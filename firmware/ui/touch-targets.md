# Front panel 触摸热区设计

本文件定义前面板可交互界面的热区几何、命中层级和边界行为。固件运行时、preview overlay 与 host 单元测试均复用 `front_panel_scene.rs` 中的 `TouchRect` 常量和 hit-test 函数。

## 基本约束

- 坐标系为 `320x172`，左上角是 `(0, 0)`，右下角是 `(319, 171)`。
- 热区使用左闭右开矩形；例如 `x=112 w=38` 覆盖 `112..149`。
- 视觉 glyph 可以小于热区，但必须完整落在对应热区内。
- 同级操作热区不得重叠。Dashboard 卡片与顶部图标发生几何重叠时，顶部图标拥有更高命中优先级。
- 显示区以外坐标必须拒绝。手指从边框滑入后，只在中心点首次进入有效 WiFi 或告警热区时触发；其它页面仍只响应首次按下。

## 告警列表

| 入口 | 几何（px） | 行为 |
| --- | --- | --- |
| 左上返回 | `x=0 y=0 w=96 h=24` | 返回 Dashboard |
| 第 1 行主体 | `x=0 y=24 w=272 h=36` | 打开详情 |
| 第 1 行声音 | `x=272 y=24 w=48 h=36` | 消音 |
| 第 2 行主体 | `x=0 y=60 w=272 h=36` | 打开详情 |
| 第 2 行声音 | `x=272 y=60 w=48 h=36` | 消音 |
| 第 3 行主体 | `x=0 y=96 w=272 h=36` | 打开详情 |
| 第 3 行声音 | `x=272 y=96 w=48 h=36` | 消音 |
| 底部提示栏 | 无触摸热区 | 仅显示物理按键提示 |

同一行的主体与声音热区在 `x=272` 接壤而不重叠；行间无缝接壤。`y=132..139` 保留为 8px 防误触带。
列表正文空白区和底部提示栏均不绑定返回操作；触摸左上角可见 `BACK` 或按物理 `LEFT` 返回 Dashboard。

## 告警详情

| 入口 | 几何（px） | 行为 |
| --- | --- | --- |
| 顶部返回 | `x=0 y=0 w=96 h=32` | 返回列表 |
| 消音 | `x=264 y=72 w=56 h=40` | 消音当前实例 |

两个热区互不重叠；详情正文和底部物理按键提示栏不绑定隐式触摸操作。底部 `LEFT BACK` 只说明物理左键行为，触摸返回入口固定保留在左上角。

## 自动化门禁

Host 单元测试必须覆盖：

- 每个 `TouchRect` 的精确 `x/y/w/h`、面积以及是否完整位于屏幕内；
- 同级热区的互斥、接壤边界、死区和首末像素；
- Dashboard 的 `Alerts > WiFi > Output` 命中优先级，并逐像素扫描整个 `320x172` 屏幕；
- CST816D `LandscapeSwapped` 坐标映射的四角、兼容坐标顺序和越界拒绝；
- 顶部 WiFi/Alerts 的首次按下、从其它区域滑入、同区移动不重复触发，以及 Alerts 不可用状态。

标记图必须由 firmware preview framebuffer 生成，并使用同一组 `TouchRect` 常量绘制 overlay。修改热区常量、命中层级或触摸进入策略时，相关 host 测试与 preview 矩阵必须同时通过。
