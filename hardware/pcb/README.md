# PCB 工程

本目录存放 Mains Aegis 主板与前面板的 PCB 设计资料。当前文件来自同一套 EDA 工程导出：

- `ProPrj_MainsAegis.epro2`：PCB 工程入口文件。
- `SCH_Main.pdf` / `SCH_Panel.pdf`：主板与前面板原理图导出。
- `PCB_Main.pdf` / `PCB_Panel.pdf`：主板与前面板 PCB 图导出。
- `Netlist_Main.enet` / `Netlist_Panel.enet`：主板与前面板网表。
- `Gerber_Main.zip` / `Gerber_Panel.zip`：主板与前面板制造文件。

板级设计说明、网络解释和检查记录见 [`docs/pcbs/`](../../docs/pcbs/)。
